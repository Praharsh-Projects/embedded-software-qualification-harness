# Changelog

All notable changes are documented in this file. The project follows Semantic
Versioning for its own configuration baselines; that versioning is not a claim
of product certification or production readiness.

## [Unreleased]

### Added

- Freestanding C11 build target for a generic ARM Cortex-M0+ artifact.
- Host-executable models of UART, SPI, classic CAN, and bounded Ethernet-style
  datagrams.
- Deterministic controller, fault, watchdog, recovery, and telemetry logic.
- Unit, integration, and qualification tests.
- Python qualification runner and machine-readable requirements.
- SRS, SSDD, ICD, SQTP, test procedures, configuration index, traceability, and
  limitations documentation.
- Ubuntu/macOS host verification and Ubuntu ARM cross-build CI.

## [0.1.0] - 2026-07-26

- Initial portfolio baseline.
